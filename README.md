# Gun2D

A Gun2D node that lets you fire different types of bullets towards the mouse

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/Gun2D.git
```

## Documentation
https://github.com/ChillCube/Gun2D/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon Gun2D
```

## For Developers
```bash
push-all-addons
```

## Dependencies

- [GodotBullet](https://github.com/ChillCube/GodotBullet)
- [RotateToMouse](https://github.com/ChillCube/RotateToMouse)
